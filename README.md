# Cheminformatics Virtual Laboratory

An interactive web-based learning laboratory designed to introduce students to cheminformatics, molecular representation, visualization, descriptors, and chemical structure recognition.

## Features

### SMILES Toolkit

- Enter and interpret SMILES notation
- View molecular formulas
- Try example molecules such as ethanol, benzene, and methane
- Open molecules in the visualizer

### Molecular Visualization

- View molecules in a 2D ball-and-stick style
- Explore a 3D preview mode
- Visualize ethanol, benzene, and methane
- Identify atoms using standard molecular colours

### Molecular Descriptors

The application displays:

- Molecular weight
- LogP
- Topological polar surface area
- Hydrogen bond donors
- Hydrogen bond acceptors
- Rotatable bonds
- Ring count

### Molecule Colour ID

An interactive quiz covering standard CPK atom colours:

- Oxygen
- Hydrogen
- Carbon
- Nitrogen

### Spot the Error Game

A true-or-false chemistry game that tests knowledge of:

- Atom colour conventions
- Molecular modelling
- Chemical representation
- CPK colour standards
